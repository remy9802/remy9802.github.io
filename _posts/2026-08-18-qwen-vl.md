## 核心结论

Qwen-VL 把自然语言回答、OCR 和 bounding box 定位统一为文本生成，证明早期 LVLM 可以在一个接口中兼顾通用问答与细粒度感知。其固定 448×448 分辨率和 256 个视觉 token 也清楚暴露了长文档、极端长宽比与视频任务的视觉带宽瓶颈。

## 研究背景

2023 年的开放多模态模型主要沿用“冻结视觉编码器 + 语言模型 + 轻量连接器”范式。Flamingo 强调图文交错和 few-shot，BLIP-2 用 Q-Former 压缩图像，LLaVA 证明视觉指令微调能形成聊天能力；但这些模型通常以英文自然图像为主，固定低分辨率会丢失文档文字，输出也缺少统一的区域定位协议。

Qwen-VL 的研究背景还包括中文与 OCR 场景的实际需求。论文希望同一个开放模型既回答问题，也能把文本实体和图像区域互相对应。因此它不仅增加视觉输入，还把 bounding box 设计成语言序列的一部分，为后来的文档理解、GUI 操作和视觉 agent 奠定接口基础。

## 研究问题

2023 年的开放 LVLM 多聚焦自然图像问答，输入分辨率低，难以读取文字或精确定位目标。论文研究怎样在 Qwen 语言模型上增加视觉感知器和统一输入输出格式，使同一模型完成 caption、VQA、OCR、文档理解、视觉定位和多轮对话。

## 方法与数据

![Qwen-VL 参数组成与三阶段训练](/images/literature-notes/qwen-vl/method-overview.png)

*图 1｜Qwen-VL 总参数约 9.6B；训练依次经历低分辨率图文对齐、高分辨率多任务预训练和视觉指令微调。雪花表示冻结、火焰表示更新。来源：原论文表 1、图 3。*

完整前向路径是：图像经 ViT-bigG 形成 patch 网格；adapter 的 256 个 query 通过 cross-attention 读取网格并形成固定长度视觉序列；视觉 token 被插入 Qwen 文本上下文；Qwen 自回归生成答案、区域坐标或多轮对话。三阶段训练逐步从“建立模态对应”转为“学习细粒度任务”，最后再做交互对齐，冻结策略也随阶段变化。

### 架构

Qwen-VL 由 Qwen-7B（实际约 7.7B）、OpenCLIP ViT-bigG（1.9B）和 position-aware adapter（0.08B）组成，总计约 9.6B 参数（表 1）。ViT 以 stride 14 切 patch；448×448 输入产生 1024 个视觉特征，adapter 用 256 个 learnable queries 做单层 cross-attention，将其固定压缩为 256 个视觉 token。cross-attention 的 query/key 叠加二维绝对位置编码，以缓解压缩造成的位置丢失。

图像 token 用 `<img>...</img>` 包围。bounding box 坐标归一化到 `[0,1000)`，写成普通字符串并用 `<box>` 标记；对应文本实体用 `<ref>` 标记。统一文本接口使模型既能“根据描述找区域”，也能“根据区域生成描述”，但坐标精度受字符串生成和固定图像尺寸共同限制。

### 三阶段训练

1. **图文预训练**：从约 5B 原始图文对清洗至 1.4B（英语 77.3%、中文 22.7%），图像为 224×224；冻结 Qwen，只训练 ViT 和 adapter。训练 50k 步、全局 batch 30,720，论文称消费约 1.5B 图文样本、500B 图文 token。
2. **多任务预训练**：升至 448×448，解冻全模型；混合 19.7M caption、3.6M VQA、3.5M grounding、8.7M referring grounding、8.7M grounded caption、24.8M OCR 和 7.8M 纯文本样本（表 3），训练 19k 步。
3. **监督指令微调**：冻结视觉编码器，训练 LLM 与 adapter；约 350k 指令包含多轮对话、定位、多图和纯文本，得到 Qwen-VL-Chat，训练 8k 步。

adapter 查询数消融显示 64/144/256/400 个 query 的早期收敛与最终损失存在折中，作者选 256 以适配第二阶段 1024 个 patch。高分辨率 window attention 虽把 896×896 训练从 60 s/iter 降至 25 s/iter，但收敛损失更高；最终模型仍采用全局 attention（附录 E.2-E.3）。

## 实验

### 任务与协议

评价覆盖自然图像 caption/VQA、知识问答、OCR/文档/图表、referring expression、few-shot 和开放指令跟随。传统任务使用 CIDEr、VQA score、ANLS、accuracy 等数据集指标；TouchStone 将人工细粒度描述交给文本 GPT-4 作裁判；SEED-Bench 的视频能力仅通过均匀抽取 4 帧测试，并非原生时序编码。

### 通用视觉与文字理解

![Qwen-VL 图像描述与通用 VQA 结果](/images/literature-notes/qwen-vl/key-results.png)

*图 2｜图像描述和通用 VQA 主表。Qwen-VL 在 Flickr30K、VQAv2、OKVQA 和 GQA 上领先多数同期通用模型；灰色 Specialist SOTA 使用更大或任务专用系统，不应与开放通用模型直接等价比较。来源：原论文表 4。*

| 模型/版本 | VQAv2 | OKVQA | TextVQA | DocVQA | ChartQA | 证据定位 |
|---|---:|---:|---:|---:|---:|---|
| Qwen-VL | 79.5 | 58.6 | 63.8 | 65.1 | 65.7 | 表 4-5 |
| Qwen-VL-Chat | 78.2 | 56.6 | 61.5 | 62.6 | 66.3 | 表 4-5 |
| InstructBLIP-13B（论文对照） | - | - | 50.1 | - | - | 表 5 |

预训练版在 OCR/文档上很强，但 Chat 版在多项封闭基准下降，说明指令对齐改变了输出分布，不能只用“Chat 是升级版”理解两者。Qwen-VL 的 NoCaps/Flickr30K zero-shot CIDEr 为 121.4/85.8，通用 VQA 与 caption 也具竞争力，但许多对照的训练数据、输入分辨率和提示并不相同。

### 定位与开放指令

RefCOCO val/testA/testB 为 89.36/92.26/85.34，RefCOCO+ 为 83.12/88.25/77.21，RefCOCOg val-u/test-u 为 85.58/85.48（表 6）。这些结果证明文本坐标接口可用于通用 grounding，但训练已包含 RefCOCO 系列数据，不是 zero-shot 定位。

TouchStone 汇总英语、中文、多图、文本识别、图表等真实指令，用 GPT-4 根据人工转写的图像描述评分。Qwen-VL-Chat 在论文协议中领先同期开放模型，尤其中文和文本读取；不过裁判看不到原图，任何描述遗漏都会成为评价上限。

### 计算与分辨率消融

ViT 输入由 448 升到 896 时，全局 attention 的单步时间从 10 秒增至 60 秒；window attention 为 9 秒和 25 秒（表 10）。作者最终没有采用 896，因为即使其损失接近 448 配置，训练仍约慢 2.5 倍。该消融直接解释了第一代 Qwen-VL 为何停在固定 448×448，也预示 Qwen2-VL 必须改变视觉 token 机制。

## 主要发现

1. **文字读取是第一代模型的强项。** Qwen-VL 在 TextVQA、DocVQA、ChartQA 上分别报告 63.8、65.1、65.7，明显高于论文列出的同规模通用模型（表 5）。
2. **文本坐标足以实现通用 grounding。** RefCOCO val 为 89.36，RefCOCO+ val 为 83.12，RefCOCOg val-u 为 85.58（表 6），说明无需单独检测头也能生成定位结果。
3. **聊天对齐会牺牲部分基础能力。** Qwen-VL-Chat 在 TextVQA、DocVQA、OCR-VQA 等多项传统任务上低于预训练版，例如 TextVQA 从 63.8 降到 61.5（表 5）。SFT 提升人机交互并不保证所有能力保留。
4. **指令评价依赖模型裁判。** TouchStone 使用文本 GPT-4 读取人工细粒度图像描述后打分（表 7），适合比较同协议模型，但存在裁判偏好和图像信息转写误差。

## 结论

作者认为，经过大规模图文对齐、多任务训练和 SFT，Qwen-7B 可以扩展为兼具理解、定位、文字读取和对话的多语言视觉助手，并以公开模型支持后续研究。

## 局限与适用边界

### 作者路线本身的限制

- 固定 448×448 输入和 256 视觉 token 会丢失小字、长页和极端长宽比细节，不适合原生长视频。
- 1.4B 图文数据包含内部数据，完整清洗、去重和 benchmark 污染情况无法审计。
- 技术报告未同行评审；TouchStone 又依赖 GPT-4 裁判，结论的外部有效性有限。
- 聊天版在部分基础基准退化，提示通用对话与任务专精之间存在后训练权衡。
- 坐标是文本格式，并未自动保证几何一致性或高精度检测性能。
- 视频评价只抽 4 帧，缺少运动方向、事件顺序和长时依赖的结构性建模；不能据此称为完整视频模型。
- 第一、二阶段使用大量网页和内部数据，却未给出系统的 benchmark 去污染分析，表格中的“zero-shot”只描述任务微调状态，不保证训练语料从未出现样本。
- grounding 坐标量化到 1000 档且绑定缩放后的图像，适合粗粒度区域交互，不等同于检测器的像素精度与置信度校准。

## 我的思考

Qwen-VL 的历史意义是把 OCR 与 grounding 提升为通用 MLLM 的基础能力，而不是外挂工具。它也给后续 Qwen2-VL 指出明确问题：视觉 token 数不能固定，位置表示必须适配任意分辨率和视频。评估时应把 Qwen-VL 看作代际起点，而不是与 2025 年模型直接拼榜。
