## 核心结论

BLIP-2 把视觉—语言预训练拆成两个较容易优化的问题：第一阶段只面对冻结视觉编码器，训练 Q-Former 从大量 image tokens 中抽取与文字有关的 32 个 query 表示；第二阶段再把这 32 个表示线性投影为冻结 LLM 的 soft visual prompts。视觉主干和 LLM 在预训练时都不更新，训练集中在桥接模块。[原文 Figures 2–3、§3](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

这一设计的强证据有两层。其一，Figure 5 显示若跳过第一阶段表示学习，OPT 与 FlanT5 路线的零样本 VQA 都显著更低，OPT 还随第二阶段训练继续而退化；单纯用 language-modeling loss 无法可靠跨越 modality gap。其二，ViT-g + FlanT5-XXL 在零样本 VQAv2 test-dev 达到 65.0，比 Flamingo-80B 的 56.3 高 8.7 个分数点，但 OK-VQA 45.9 仍低于 Flamingo 的 50.6。[原文 Figure 5、Table 2](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

“参数高效”必须限定口径：论文 Table 1 以 188M 预训练参数与 Flamingo 的 10.2B 相比，得到约 54 倍差异；完整推理模型仍包含最高约 12.1B 总参数。少训练参数不等于低推理显存、低延迟或小部署模型。

## 研究背景

BLIP 通过统一 MED 同时学习理解和生成，但视觉编码器、融合模块和文本模型仍需共同训练。随着视觉塔和 LLM 扩展到数十亿参数，端到端图文预训练的显存、通信与数据成本迅速增加；同时，以有限图文数据更新预训练 LLM 还可能破坏其已有语言能力。

另一条路线是冻结单模态骨干，只训练轻量连接器。问题在于，LLM 从未在预训练中见过图像 embedding，视觉特征的分布和语义粒度与文本 token 不同。若直接用图像条件语言建模训练投影层，桥接器既要从高维 patch tokens 中提炼语义，又要一次性适配 LLM，容易形成优化瓶颈。

## 研究问题

BLIP-2 因此问：

1. 能否用一个固定长度的 learnable-query 模块压缩任意视觉 token 序列？
2. 能否先学“哪些视觉信息与文本相关”，再学“怎样把这些信息写进 LLM embedding 空间”？
3. 冻结骨干是否仍能支持检索、描述、VQA 和指令式零样本生成，而不仅是单一 caption 任务？

## 方法与数据

### 1. Q-Former：32 个查询构成视觉信息瓶颈

Q-Former 由两个共享 self-attention 的 Transformer 子模块构成：image transformer 通过每隔一个 block 插入的 cross-attention 读取冻结图像特征；text transformer 可作为文本 encoder 或 decoder。其主体从 BERT-base 初始化，新增 cross-attention 随机初始化。

论文使用 32 个可学习 query，每个 768 维：

$$
Z=Q_{\phi}(Q_0,E_{\mathrm{img}}(I)),
\qquad Z\in\mathbb R^{32\times768}.
$$

例如 CLIP ViT-L/14 输出 $257\times1024$ tokens，而 Q-Former 始终输出 32 个向量，长度与输入图像分辨率无关。这不仅是降维，也是一种受语言目标约束的选择性瓶颈：模型被迫只保留能帮助图文对齐和生成的信息。[原文 §3.1](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

### 2. 第一阶段：面对冻结视觉塔学习表示

![BLIP-2 第一阶段的 Q-Former 与 attention masks](/images/literature-notes/blip2/qformer-stage1.png)

*图 1｜Q-Former 用同一组参数和三种 self-attention mask 联合优化 ITC、ITG 与 ITM；不同 mask 控制 query 与文本能否互相读取。来源：原论文 Figure 2，PMLR PDF 第 3 页。[原图](https://proceedings.mlr.press/v202/li23q/li23q.pdf)*

第一阶段冻结图像编码器，联合优化三项目标：

#### Image–Text Contrastive Learning（ITC）

使用 unimodal mask，query 和 text 相互不可见。文本取 `[CLS]` 表示 $t$，图像有 32 个 query 表示 $z_q$；一对图文的相似度取最相关 query：

$$
s(I,T)=\max_{q=1\dots32}
\langle \hat z_q,\hat t\rangle.
$$

再对 batch 内样本做双向对比交叉熵。由于视觉塔冻结、单卡可容纳更大 batch，作者直接使用 in-batch negatives，不再沿用 BLIP 的 momentum queue。

#### Image-grounded Text Generation（ITG）

使用 multimodal causal mask：queries 彼此可见，但不能读取文本；每个文本 token 可读取所有 queries 和先前文本。`[CLS]` 被 `[DEC]` 替换，目标为：

$$
\mathcal L_{\mathrm{ITG}}
=-\sum_j \log p(w_j\mid w_{<j},Z).
$$

冻结图像编码器与文本 token 不直接交互，所以 caption 所需信息必须先穿过 32-query 瓶颈。这使 ITG 不只是生成训练，也迫使 queries 覆盖可语言化的视觉内容。

#### Image–Text Matching（ITM）

使用双向 mask，让 query 和文本完全交互。每个 query 输出进入二分类头，再对 32 个 logit 取平均，判断图文是否匹配；ITC 相似度用于挖 hard negative image/text。

论文将第一阶段概括为：

$$
\mathcal L_{\mathrm{stage1}}
=\mathcal L_{\mathrm{ITC}}
+\mathcal L_{\mathrm{ITG}}
+\mathcal L_{\mathrm{ITM}}.
$$

完整第一阶段 Q-Former 含 188M 参数。官方 v1.0.2 实现进一步显示三项损失等权相加，ITC 使用可学习温度并对两个方向取均值；这些属于代码级实现细节，不应误写成正文全部明确给出的公式。

### 3. 第二阶段：把视觉 queries 变成 LLM 的软提示

![BLIP-2 第二阶段连接 OPT 与 FlanT5](/images/literature-notes/blip2/qformer-stage2.png)

*图 2｜Q-Former 输出经全连接层映射到 LLM embedding 维度；decoder-only OPT 直接条件生成，encoder-decoder FlanT5 则把视觉提示和 prefix 送入 encoder、预测 suffix。视觉编码器和 LLM 均冻结。来源：原论文 Figure 3，PMLR PDF 第 4 页。[原图](https://proceedings.mlr.press/v202/li23q/li23q.pdf)*

全连接层将 $Z$ 投影到所选 LLM 的 token-embedding 维度：

$$
V=WZ,
$$

投影后的 32 个向量作为 soft visual prompts，置于文本 embedding 之前。第二阶段只训练 Q-Former/queries 与投影等桥接参数：

- **OPT（decoder-only）**：视觉 prompts 与文本前缀共同进入 causal decoder，优化标准 language-modeling loss；
- **FlanT5（encoder-decoder）**：把 caption 拆成 prefix/suffix，视觉 prompts 和 prefix 进入 encoder，decoder 生成 suffix，即 prefix-language-modeling loss。

论文 §3.1 称完整 Q-Former 为 188M，而 Table 2 对第二阶段具体模型列出 103–108M trainable parameters。论文正文没有解释计数差异；官方 v1.0.2 代码显示第二阶段会移除不再使用的 Q-Former 文本 embedding、分类头及 text-only FFN 路径，因此两者不能当作同一阶段的矛盾参数量直接比较。

### 4. 冻结策略的精确边界

“冻结视觉编码器与 LLM”指 **两阶段预训练**。下游并非始终只更新 Q-Former：

- 零样本 VQA/指令生成直接使用预训练组件；
- 图文检索不接 LLM，微调图像编码器与 Q-Former，并用 ITC 先选 128 个候选、ITM 再排序；
- COCO caption 与有监督 VQA 微调时，LLM 保持冻结，但图像编码器和 Q-Former会更新；VQA 还把问题文本同时送入 Q-Former，使 queries 聚焦问题相关区域。

因此 BLIP-2 是预训练参数高效路线，不应泛化为“所有下游训练都只调 100M 参数”。[原文 §§4.2–4.4、Figure 7](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

### 5. 数据、骨干与训练成本

数据沿用 BLIP 的约 129M 图像：COCO、Visual Genome、CC3M、CC12M、SBU 和约 115M LAION 图像。作者用 BLIP-large 为每张网页图像生成 10 个 captions，再将原始文本和合成文本一起用 CLIP ViT-L/14 排序，保留前两条，每个训练 step 随机选一条。

视觉塔比较 CLIP ViT-L/14 与 EVA-CLIP ViT-g/14，移除最后一层、使用倒数第二层特征；语言侧比较 OPT-2.7B/6.7B 与 FlanT5-XL/XXL。第一阶段训练 250k steps，第二阶段 80k；输入 $224\times224$。最大 ViT-g + FlanT5-XXL 设置在 16 张 A100 40GB 上，作者报告第一阶段少于 6 天、第二阶段少于 3 天。[原文 §§3.3–3.4](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

## 实验

### 1. 零样本多任务与 VQA

![BLIP-2 零样本结果与 VQA 规模对照](/images/literature-notes/blip2/key-results.png)

*图 3｜上表汇总 VQA、NoCaps 和 Flickr 零样本结果；下表拆分视觉塔/LLM 组合，并同时报告 trainable 与 total parameters。BLIP-2 在 VQAv2 强于 Flamingo-80B，但在 OK-VQA 落后。来源：原论文 Tables 1–2，PMLR PDF 第 6 页。[原表](https://proceedings.mlr.press/v202/li23q/li23q.pdf)*

关键数字如下：

| 模型 | Trainable / Total | VQAv2 test-dev | OK-VQA test | GQA test-dev |
|---|---:|---:|---:|---:|
| Flamingo-80B | 10.2B / 80B | 56.3 | **50.6** | — |
| BLIP-2 ViT-g + OPT-6.7B | 108M / 7.8B | 52.6 | 36.4 | 36.4 |
| BLIP-2 ViT-g + FlanT5-XL | 107M / 4.1B | 63.0 | 40.7 | 44.2 |
| BLIP-2 ViT-g + FlanT5-XXL | 108M / 12.1B | **65.0** | 45.9 | **44.7** |

同一 LLM 下 ViT-g 通常优于 ViT-L；同一家族更大的 LLM 通常更强；instruction-tuned FlanT5 在 VQA 上显著优于未指令化的 OPT。这支持模块化复用强单模态模型，但也说明结果同时来自视觉塔、LLM 和桥接 recipe，不能只归因于 Q-Former。

### 2. 第一阶段表示学习不是可省略的预热

![BLIP-2 第一阶段表示学习消融](/images/literature-notes/blip2/representation-ablation.png)

*图 4｜跳过 representation learning 后，OPT 与 FlanT5 两条路线的零样本 VQA 都显著下降；OPT 甚至随第二阶段训练继续而退化。来源：原论文 Figure 5，PMLR PDF 第 7 页。[原图](https://proceedings.mlr.press/v202/li23q/li23q.pdf)*

Figure 5 是方法最关键的因果消融。它表明直接把 Perceiver/Q-Former 类连接器仅用 LM loss 接到 LLM，并不能稳定获得视觉对齐。ITC/ITM/ITG 的第一阶段先把 queries 变成语言相关视觉表示，第二阶段才主要承担分布映射。

不过这个消融比较的是“完整第一阶段”和“完全没有第一阶段”，没有逐项拆开 ITC、ITM、ITG 对零样本生成的独立贡献。Table 6 只在检索微调中显示加入 ITG 后 COCO image-to-text / text-to-image Recall@1 从 84.5/67.2 提至 85.4/68.3。

### 3. Caption、检索与有监督 VQA

- **NoCaps 零样本描述**：ViT-g + FlanT5-XL 达到 CIDEr 121.6、SPICE 15.8，高于 BLIP 的 113.2/14.8；COCO 微调后的 CIDEr 为 144.5，低于表中 OPT-2.7B 的 145.8，也低于 OFA 145.3 的程度很小，不能说所有 caption 指标均由最大 LLM 最优。
- **Flickr30K 零样本检索**：ViT-g 的 image-to-text / text-to-image Recall@1 为 97.6/89.7；COCO 微调后为 85.4/68.3。检索时不使用 LLM，因此这些结果主要评估第一阶段 Q-Former 与视觉塔。
- **有监督 VQAv2**：ViT-g + OPT-6.7B 的 test-dev/test-std 为 82.19/82.30；高于开放生成模型 BLIP 的 78.25/78.32，与 Flamingo-80B 82.00/82.10 接近，但低于 closed-ended BEIT-3 的 84.19/84.03。开放生成与闭集分类的输出协议不同，不宜只按最高分直接排序。[原文 Tables 3–5](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

### 4. 论文自己展示的失败案例

![BLIP-2 的错误输出案例](/images/literature-notes/blip2/failure-cases.png)

*图 5｜作者把错误分为知识归属错误、激活错误推理路径和信息过时：错误引用爱因斯坦、忽略加拿大冬季天气、把 iPhone 14 识别成 iPhone 11。来源：原论文 Figure 6，PMLR PDF 第 12 页。[原图](https://proceedings.mlr.press/v202/li23q/li23q.pdf)*

这些例子直接否定了“冻结 LLM 知识即可保证视觉问答事实可靠”的强解释。视觉提示可能把 LLM 引向错误知识路径；冻结还意味着知识无法在图文预训练阶段更新。

## 主要发现

1. **桥接应分解为“视觉—文本表示对齐”和“视觉—LLM 生成对齐”。** Figure 5 表明二者不能简单合并成一次 LM 训练。
2. **Q-Former 是有监督信息瓶颈，而非普通线性投影。** 32 queries 通过 ITC/ITM/ITG 学会选择可语言化视觉证据。
3. **冻结策略保留单模态能力并降低训练成本，却没有降低完整模型体量。** 12.1B 总参数仍需在推理时加载。
4. **更强视觉塔与更强 LLM 均可带来增益。** 这体现模块化优势，也使 Q-Former 的单因素贡献更难从跨模型结果中分离。
5. **检索和生成走不同部署路径。** 检索直接使用第一阶段 Q-Former，不需要 LLM；生成才需要第二阶段视觉 prompts。
6. **开放知识仍是边界。** VQAv2 强不代表 OK-VQA、时效知识和视觉事实推理同样可靠。

## 结论

BLIP-2 证明可以冻结视觉编码器和 LLM，通过两阶段训练的 Q-Former 建立参数较少的跨模态接口。它把 BLIP 的三目标学习从“统一完整模型”迁移到“训练桥接器”，并成为后来多模态 LLM 中 query-based connector 的代表方案。[原文 Conclusion](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

## 局限与适用边界

### 作者明确报告的局限

- 论文没有观察到给 LLM 提供少量 VQA 示例后产生 in-context learning 增益。作者将其归因于预训练样本只有单个 image-text pair，缺少多图文交错序列。
- 图像到文本生成会因 LLM 知识错误、错误推理路径或信息过时而失败。
- 冻结模型会继承 LLM 的风险，包括冒犯性语言、社会偏见和隐私信息泄漏；作者建议用更安全的指令与过滤数据缓解。[原文 §5](https://proceedings.mlr.press/v202/li23q/li23q.pdf)

### 额外识别的局限

- 32-query 固定瓶颈非常适合整图语义，却可能丢失 OCR、小物体、区域定位、稠密几何和高分辨率文档细节；本文没有系统评估这些任务。
- 所谓 54× 参数优势只计算预训练时可更新参数，不代表总参数、训练数据成本、推理延迟、显存或能耗同等缩小。
- 129M 图像、BLIP captioner 和 CLIP 排序器共同决定数据质量；Q-Former 不是唯一变化因素，数据生成链也会继承旧模型偏差。
- 最强公开数字来自不同视觉塔与 LLM 组合，跨模型表格没有严格配平总参数、预训练语料和算力。
- 下游 caption/VQA/检索会解冻视觉塔；“冻结骨干”不能无条件延伸到所有使用场景。
- 论文所谓 zero-shot VQAv2 是未使用 VQA 标注，并非图像域完全未见：预训练数据明确包含 COCO，而 VQAv2 建立在 COCO 图像之上；Flickr/LAION 的潜在网页重叠也未做系统去污染审计。
- 精选指令生成主要借用了 FlanT5 已有 instruction tuning；BLIP-2 本身以 caption-style 图文对预训练，不等同于后来的多任务视觉指令微调。
- 零样本 VQA 使用固定 prompt、beam size 5 和 length penalty -1，结果包含解码协议影响；论文没有系统报告 prompt sensitivity。
- 实验主要给出单点指标，没有随机种子、误差条或显著性检验。
- PMLR 正文存在 AdamW 下标和失败图编号排版错误；虽然不改变主结果，精确复现应对照官方代码和附录。
- 冻结 LLM 无法自动更新事实，也无法保证视觉 evidence 被正确绑定到语言知识；Figure 6 已给出直接反例。

## 我的思考

BLIP-2 真正改变的是多模态系统的分工：视觉塔负责高容量感知，LLM 负责语言与知识，Q-Former 负责把“所有视觉 token”变成“当前语言任务需要的少量证据”。这比把图像粗暴映射成一个 token 更有表达力，也比让 LLM 对全部高分辨率 patch 做 full attention 更节省上下文。

但 query bottleneck 不是免费压缩。它优化的是网页 caption 可表达的信息，而机器人操作、自动驾驶、文档和医学影像常需要位置精确、不可遗漏的细节。后续连接器设计应把“固定少量语义 queries”和“可变长度/区域保真 tokens”结合，并显式测量压缩后丢失了什么，而不是只测最终 VQA 平均分。
